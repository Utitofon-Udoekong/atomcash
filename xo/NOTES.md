Technical notes for the Build with XO write-up. The bounty rejects an AI-written personal essay, so this file is a list of facts to rewrite in your own words. It is not the submission essay.

- Engine package: `@xo-cash/engine@0.1.1-next.18170561234`, which pulls `@xo-cash/state@0.0.5`, `@xo-cash/templates@0.0.12`, and `@xo-cash/utils@0.0.10`. `scripts/xo-chipnet.ts` calls `Engine.create`, `importTemplate`, `setDefaultPolicies`, `generateLockingBytecodeFromDefaultPolicy`, `createInvitation`, and `executeAction({ broadcastTransaction: true })`.
- XO locking type `p2sh` compiles as P2SH32. The redeem script pushes `fee`, `tokenAmount`, `tokenCategory`, `refundLock`, `payoutLock`, `secretHash`, and `timeout`, then the compiled AtomSwap body. Integer values use the same VM number encoding as SolidCash `encodeInt`. Byte values are the raw constructor bytes. Empty category is `0x`.
- For one offer, that compiled locking bytecode equalled `Contract.lockingBytecode`, and the cashaddr equalled the address `instantiate` returns. The check is at the start of `scripts/xo-chipnet.ts`.
- Chipnet refund broadcast by the engine: fund `b2e7968a5b4898085cad96dd358cb974601b357408bdf126967c0d63fe36b030`, refund `d48630e8cd953841810d0d14029485811154f7362c7f41736f8e089759a1f16a`, invitation `xo/invitation.json`, address `bchtest:pw5afw7xs59dphfy9g98u8rug90s2dll2yseduhw04ajqdhl3r76q8szw335r`. Timeout was 1, so the refund was valid immediately. No preimage is in the invitation.
- blaze.xo.cash, chipnet account: Import Template with `xo/atom-swap.template.json`, then Join Invitation with `xo/invitation.json`, then View invitation. The result block shows refund transaction `d48630e8cd953841810d0d14029485811154f7362c7f41736f8e089759a1f16a`. The template must be imported before the invitation. This was done once in the inspector.
- What got in the way: `pnpm` on this machine has no `npm` binary, so the version came from the registry `next` tag. IndexedDB storage needs the `sqlite3` native module and SQLite storage needs `better-sqlite3`; both install scripts had to be run by hand. An outpoint has to be a `Uint8Array` of the display-order txid. `JSON.stringify` turns those bytes into an object; `serializeInvitation` from `@xo-cash/utils` is the form blaze accepts.
